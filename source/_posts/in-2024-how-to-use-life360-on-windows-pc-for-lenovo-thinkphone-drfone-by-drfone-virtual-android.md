"Location Not Available" means that the Lenovo ThinkPhone device is not currently sharing its location with the Find My app. This can happen if the Lenovo ThinkPhone device is in Airplane mode or if the user has turned off location sharing for the Find My app. It can also happen if there is a temporary issue with the iCloud servers.
